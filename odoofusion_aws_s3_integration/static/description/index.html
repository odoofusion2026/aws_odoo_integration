CLOUD STORAGE FOR ODOO

Move Supported Odoo Attachments to Amazon S3

The Odoo AWS S3 Integration module connects Odoo 18 with Amazon Simple Storage Service and automatically routes attachments, product images, and web assets from any Odoo model to your configured S3 bucket.

Users continue uploading and opening files through Odoo, while administrators gain better control over cloud storage, bucket browsing, synchronization activity, and attachment lifecycle management.

Universal Model Scope

This version supports attachments, product images, and web assets linked to any Odoo model (e.g. product.template, sale.order, account.move, etc.).

ATTACHMENT WORKFLOW

How Odoo AWS S3 Attachment Storage Works

A simple four-step process that keeps the user experience inside Odoo.

1

Upload

A user uploads an attachment or a product image/web asset through any Odoo record interface.

2

Rule Check

The module evaluates the active storage rule configured for that specific Odoo model.

3

S3 Storage

The file is stored using AWS S3 Only, Dual Storage, or Odoo Only mode.

4

Retrieve

Odoo retrieves and serves the attachment from its configured storage location.

QUICK SETUP

Configure Odoo AWS S3 in Two Steps

01

Connect Your S3 Bucket

  1. Open AWS S3 → Configuration → Buckets Setup.
  2. Create a bucket connection or edit an existing one.
  3. Enter the bucket name, AWS region, access key ID, and secret access key.
  4. Run Test Connection and save the configuration.
02

Create a Sync Rule

  1. Open AWS S3 → Configuration → Sync Rules.
  2. Create a rule for sale.order.
  3. Choose AWS S3 Only, Dual Storage, or Odoo Only.
  4. Set an optional folder prefix such as Sales/.
  5. Activate the rule.

FAQ

Frequently Asked Questions

Which Odoo records are supported?

It supports all records and attachments across Odoo, including product templates, sale orders, invoices, web assets, and custom models.

Can files remain in Odoo after being uploaded to S3?

Yes. Use Dual Storage to keep copies in both Odoo and Amazon S3.

Can administrators browse S3 files from Odoo?

Yes. The built-in file explorer provides folder browsing, search, file information, download, and permitted delete actions.

Does the module include synchronization reporting?

Yes. The dashboard shows connection health, successful uploads, failures, recent activity, and related Odoo records.
