Core Features

Automated S3 Routing Rules

Automatically route attachments to specific S3 folders based on configurations. You can define target folders dynamically for your models.

Note: Current integration is explicitly configured and restricted to **Sale Orders** (`sale.order`) for maximum security and business compliance.
Storage Modes
  • AWS S3 Only: Uploads to S3, deletes the local Odoo copy, and stores a light pointer. Saves maximum database space.
  • Dual Storage: Stores files both on AWS S3 and local Odoo database/filestore for backup or regulatory compliance.
  • Odoo Only: Standard Odoo attachment storage.

AWS S3 File Explorer

Browse, search, and download your S3 files directly from Odoo! The built-in file explorer lets you interact with files on S3 buckets in real time, eliminating the need to log into the AWS Console.

  • Browse directories and open subfolders.
  • Download files directly to your device.
  • Delete files securely with permissions.
Real-time S3 Bucket Browser

Access bucket contents, view file sizes, and track last modified times directly from Odoo's interface.

Sync Monitor Dashboard

Track the performance and health of S3 file syncing. View bucket connection statuses, sync success counts, sync failures, and log details at a single glance.

  • KPI Widgets: Quick view of counts and statistics.
  • Recent Upload Logs: Full log table detailing file type icons and timestamps.
  • Direct Links: Navigate to Odoo source records (e.g., Sale Orders) in one click.

Workflow: Attachment Lifecycle

1
Upload

User uploads a file on a Sale Order (chatter or attachment button).

2
Rule Check

Odoo intercepts the write and detects active rules for the model.

3
S3 Upload

The file is uploaded to S3. Local copies are deleted (in S3 Only mode) and pointers are stored.

4
Read/Download

When requested, Odoo fetches the file from S3 and serves it transparently to the user.

Quick Configuration

AWS Credentials Setup
  1. Go to **AWS S3** -> **Configuration** -> **Buckets Setup**.
  2. Click **Create** or edit the existing bucket.
  3. Input S3 bucket parameters:
    • Bucket Name: `sma-members`
    • AWS Region: `us-east-1`
    • Access Key ID: `AKIARSPMS...`
    • Secret Access Key: `8YhvQAp...`
  4. Click **Test Connection** to verify AWS S3 access.
Sync Rule Customization
  1. Go to **AWS S3** -> **Configuration** -> **Sync Rules**.
  2. Create a new rule for `sale.order` (Sale Order).
  3. Select the Storage Mode:
    • `AWS S3 Only` (Recommended)
    • `Dual Storage`
  4. Configure Root Folder prefix (e.g. `Sales/`).
  5. Activate the rule. Newly uploaded attachments will sync automatically.
